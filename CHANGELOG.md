# Changelog

This project is cumulative: 1.0.0 contains everything from 0.1.0 onward.

## 1.0.0 - Full feature set (untested)
- Era 2 campaign (1727, three factions) and Era 3 campaign (1817, survive-to-end victory mode).
- New factions: Maratha State, Nizam, Mughals, Maratha Leaders, East India Company; new unit: Drilled Infantry.
- Ten new commanders (two flagged fictional placeholders).
- Sandbox mode: any map, any faction, rich-start option, conquest win.
- Advanced AI: personalities, army merging, wall repair, development, objective planning by value, weakness and distance.
- Procedurally generated sound effects with an on/off setting (no audio files).
- Low-processor mode for battery; release checklist; save format v3.
- Timeline extended 1627-1818.

## 0.4.0 - Expand Era I
- Second campaign: The Expedition of 1659 (10 territories, 4 forts, 12 turns).
- Scenario picker; data now lives in data/campaigns/<id>/.
- New commanders: Afzal Khan, Netaji Palkar (assignment flagged uncertain), Siddi Jauhar.
- Timeline extended with the 1650s-1670s.

## 0.3.0 - Economy, supply, diplomacy
- Diplomacy: truces with cost, cooldown, strength and war-weariness rules.
- Territory development (+1 revenue, up to +2) and fort wall repair.
- Garrison upkeep; effective revenue shown in the info panel.
- Monsoon quarter: extra supply loss outside fort networks, slower sieges.
- Events with choices and historical notes.
- Calendar by quarters; save format v2 with automatic migration of v1 saves.

## 0.2.0 - Codex, timeline, better UI
- Codex screen (units, factions, commanders, territories, forts) with confidence tags.
- Timeline screen and in-game timeline.
- Menu hub: Armies list, Event log, Diplomacy, Timeline.

## 0.1.0 - Vertical slice
- Main menu, era select, one campaign, map, armies, combat, forts, recruitment, AI, saves.
